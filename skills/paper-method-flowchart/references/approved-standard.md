# 认可成品的视觉语法

本标准来自作者反复修改后认可的方法框架图；本地 DFQI v10 参考为作者 2026-10-08 手动强化箭头后的版本。公开包提供同一语法的通用示意图。参考指导布局与审美，当前研究决定科学定义。

## 层级与分区

白底、横向画幅；参考是 16:9，可按期刊宽度调整。顶部标题简短，下方细灰线。主模块顺着数据/决策过程排列；浅色标题带、编号圆圈、彩色虚线外框形成第一层。内部功能子区、细灰边界、短标题形成第二层。科学对象与必要图例形成第三层。

外框表示功能边界，不能替代功能图形。模块宽度按内容分配。主模块之间、上下子区之间预留箭头走廊；空隙用于分隔或转折。

| 科学对象 | 推荐视觉表达 | 必须说明 |
|---|---|---|
| 多通道输入 | 对齐的波形轨道 | 信号类别，是否示意 |
| 候选参数域 | 有轴名的小网格 | 已评估、被选择、不可行 |
| 分解表示 | 模态波形与少量谱线 | 排序依据，对象颜色 |
| 软分组 | 有浅底边界的 U 矩阵 | 行/列对象，强弱图例 |
| 组谱原型 | 可区分的频谱 | 组标签、频率轴、线型/颜色图例 |
| 判断/停止 | 紧凑接受/停止轨迹、必要条件 | 条件成立后的去向 |
| 最终表示 | 对齐模态、组谱、成员结构 | 输出与选择参数的关系 |

复合对象内部要有可读顺序，不能只把无说明图标并排摆放。

## 配色与文字

深蓝 `#0F4D92`、青 `#42949E`、绿 `#5D9F62`、紫 `#9A4D8E`、独立对照/反馈橙 `#C88931`；正文 `#252525`，边线 `#B7B7B7`，浅底 `#F1F3F5`。标题底由对应语义色淡化。重点模块可少量跳色，不让所有对象同样抢眼。避免渐变、阴影、立体装饰和卡通图标。

默认 Times New Roman。标题大于标签，标签大于小图例；图例/注释靠近对象，尽量单行。变量斜体、下标真正排版，帽子按字形中心检查。同一组合中的 K̂、Ĝ 视觉一致。综合框架默认抽象表示候选、下一点与输出，避免 `Next: (5,3)`、某实验编号、固定初始化数量。

## 清晰箭头

主流程和内部推进用黑色实心三角头，反馈/对照用橙色。参考成品内部箭头明显大于早期小箭头默认值。端点落在功能边界，线与头作为同一语义对象分组；交叉时优先改路由。

导出后检查实际方向和实心填充，不能依赖属性名称。用户手改箭头一旦认可，在后续导出中保留。

## 把历次失败转成规则

| 被否定的表现 | 改进规则 |
|---|---|
| 文字加线框堆砌 | 科学对象表达操作，框只负责分区 |
| 全是实验曲线，读不出流程 | 抽象过程为主体，数据图验证关键操作 |
| 很多诊断标签并排，没有因果关系 | 先输入—操作—输出，再布置子区 |
| 白格与画布融合 | 零值浅灰底，缺失/非法用纹理或斜线 |
| 多颜色无图例，谱线颜色接近 | 邻近小图例，颜色加线型双重编码 |
| 图例/备注比内容显眼 | 缩短文字、统一对齐，固定图例区 |
| 输出只有一句标签 | 画出模态、成员与组表示 |
| 帽子位置不一致 | 数学渲染或独立定位，再做局部 QA |

约 20% 数值示例是内容比例偏好，不是栅格图片面积阈值；原生数据曲线/矩阵也承载数据，不能只统计 PNG 面积。

## DFQI 示例的科学契约

本例先 K 后 G；条件轴上的合法候选先全部评分，再按序接受/停止。K 首次恢复条件是 OR，后续新颖性是 AND。G 首次检验对齐增益，后续检验占用、组间最大亲和与回并必要性；回并复用同一分解 M。分解后 U 不反馈求解器。贝叶斯 GP/EI 搜索是独立对照通道，不是 production DFQI 内部步骤。

上述只解释参考图，其他研究重建自己的契约。DFQI 示例也核对当前作者代码/公式，不根据图自行新增算法。

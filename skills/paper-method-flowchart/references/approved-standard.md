# 认可成品的视觉标准

本标准吸收作者对方法图的连续修改，当前参考采用三层输入模块、并列评价、最大值选择和结构化输出。公开示例用通用科学对象演示这套画法；具体研究的流程与公式由当前材料确定。

## 功能区与阅读顺序

白色画布，主模块用不同颜色的圆角虚线边界区分，标题左对齐并与模块内容留出间距。参考使用约 1.6:1 的横向画幅。根据目标版面调整比例；单栏空间不足时重新组织模块。

空间按对象数量分配。输入较多的模块可以窄而高，并列评价需要较宽区域，选择区按柱状图和公式的实际占宽安排。两行布局可按左上、右上、右下、左下的顺序阅读，用编号和连接明确推进方向。

功能子区通过位置和对齐形成层级。外框内部适当保留空白，给实心弯箭头预留走廊。大部分内容由有科学语义的图形承担，文字指出图形的名称和含义。

## 双输入模块的三层布局

顶部两路输入左右并列：观测波形置于左侧，候选域或设置置于右侧。两路输入的标题对齐，底部为短弯箭头和候选标记留出空间。中间放一个横向核心操作块。底部以对齐的模态或表示阵列展示返回对象。

每一行对应同一物理对象，每一列对应同一模态或特征；颜色随对象在后续模块中保持一致。局部缺失成分用浅底格和可见零线表示。

## 科学图形

| 对象 | 表达方式 | 邻近说明 |
|---|---|---|
| 多 ch 输入 | 同宽、同基线的波形轨道 | ch 标签和输入变量 |
| 候选域 | 带变量轴名的小网格 | 可行、非法、未评估各自的图例 |
| 返回模态 | 对齐的短波形矩阵 | 行列含义与返回变量 |
| 软分组 | 有浅底边线的成员矩阵 | 成员强弱或数值范围 |
| 频谱结构 | 分开的峰、适度调制侧峰或重叠谱 | 对象颜色与频率方向 |
| 模态复杂度 | 总量可比的能量条 | 何者表示模态能量 |
| 并列质量量 | 每项一个图形和一个数学量 | 图形与组成量逐项对应 |
| 最大值选择 | 候选分数柱与单个高亮柱 | 候选索引、选中标记、选取公式 |
| 最终重构 | 同一 ch 的模态求和与波形 | 求和方向和输入/重构图例 |

## 黑色实心弯箭头

使用闭合、填黑的原生自由形状表示主流程。箭身从贝塞尔中心线向两侧扩展，箭头与箭身连成同一形状。弯曲前后保留足够直达距离，使方向容易判断。

在 1280 × 800 参考画布中，内部箭身通常宽 4–6 个坐标单位，主路径约 5–6，箭头宽约 12–18。短箭头同步缩短箭头长度，避免只剩三角形。参数应随图件尺寸和对象密度调整。

合流采用平滑的 Y 形或圆角汇合，两路在同一方向接入主干。合流点保留连续箭身，方向箭头放在后续推进或分流位置。曲线与虚线框、标题和公式之间留出可见间距。

波形轴线和频谱基线保持细线。箭头辅助程序只处理明确给出的路径。

## 字体与数学

默认 Times New Roman。标题、功能名称、图例形成三级字号。数字和括号正体，标量变量斜体，矩阵与向量按正文符号约定。索引 `1`、`2` 使用真实下标，帽子按字形中心检查。

同类标签共用一个文字样式。例如 `ch C` 应由正体 `ch ` 和同字号的斜体 `C` 两段文字组成，位置与 `ch 1`、`ch 2` 对齐。公式图片按邻近标签的视觉字号缩放；顶端幂次、下标和帽子都要完整。

## 配色与图例

| 用途 | 默认颜色 |
|---|---|
| 主方法、选中结果 | 深蓝 `#0F4D92` |
| 一组科学对象 | 青 `#42949E` |
| 另一组对象、评价区 | 紫 `#9A4D8E` |
| 模型或软分组 | 绿 `#5D9F62` |
| 第三组对象、独立对照 | 橙 `#C88931` |
| 正文、普通边线、浅底 | `#242B32`、`#B8C0C8`、`#F1F3F5` |

实心箭头填充使用 `#000000`。颜色服务于对象类别，线型辅助区分同坐标下的曲线。零值用浅灰底与边线；非法候选用斜纹；选中候选用高亮。每种状态的图例放在对应对象附近。

综合方法图的补充说明放在正式图注或来源记录中。画布底部留给方法本身，标题放在对应对象上方。

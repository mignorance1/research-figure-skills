# 六类融合布局

按 scientific question 选布局，复用信息关系而非具体结论。

| 问题 | 主布局 | 融合信息 | 必须区别 |
|---|---|---|---|
| 比对照好多少 | 共享效应森林图 | 区间、多数据集、绝对均值列 | 不同 endpoint 单位 |
| 跨条件是否稳定 | 条件×对照热表 | 格子效应、主方法质量、排名、pooled CI | pooled 权重/单元 |
| 质量和成本权衡 | 质量—成本平面 | 方法、区间、直接标签、成本 inset | 候选数 vs 秒 |
| 参数改变修正了什么 | 景观＋边际＋归因 | 敏感性、signed contribution、net | 归因单位/覆盖总体 |
| 真实信号结构变化 | 群体平面＋预声明实例 | 配对观察、均值、额外变量、PSD/TFR | 实例选择/归一化 |
| 搜索效率能否实测 | 成本曲线＋验证带 | 预算、CI、焦点方法、实测/重建 | 不同计时总体 |

## 效应森林图＋绝对值列

一行一个对照，多数据集小纵向偏移，共享零线与横轴。颜色加标记区分数据集，完整区间；右侧数值列对齐比较行补绝对均值，焦点均值可放紧凑图例。固定控制灰色。点、区间、绝对值清楚区别；即使区间不围住点，也照端点绘制，不能截断误差条悄悄修改统计。

```sh
python skills/paper-experiment-visualization/scripts/render_effect_comparison.py --csv skills/paper-experiment-visualization/assets/examples/effect_comparison.csv --meta skills/paper-experiment-visualization/assets/examples/effect_metadata.json --out output/effect-demo
```

## 条件热表

全部预规定条件为行，各对照为列；颜色为焦点减对照的有符号效应，同时写数字。左窄列放焦点绝对值/排名。pooled 与 CI 独立底行，标权重与 cluster 单元；平均排名可放列头。排序提前确定或说明。输的条件保留负色；“大部分条件均值第一”不等于所有配对比较显著。

## 质量—成本平面

横轴明确一种成本口径，纵轴质量，焦点深蓝星、控制灰，各方法直接标签，区间留空间。小 inset 解释候选域或依赖复用。评估次数不能直接称 wall-clock 提速；例子计数和群体平均计数分开说明。

## 参数景观与归因

主区同一框架/候选域质量景观，顶/右边际共享参数刻度。侧区将各坐标 signed contribution 与 net 放相同质量单位；绝对贡献份额说明分母。负贡献保留。不同 suite 用同尺度紧凑行；不混框架和 selector 差异。

## 群体结构与真实例

两个独立结构端点构成群体平面，显示全部方法；配对观察细线连接、均值突出。符号面积编码额外变量时加大小图例。旁边展示预声明片段的原信号与全部所选模态 PSD/TFR，保留单位、共同色标、统一归一化。单模态最大值归一化隐去能量冗余，只有问题明确需要时才用并说明。

## 成本曲线与实际验证

上区预算曲线、CI、焦点方法和 exhaustive 同一成本坐标；下区紧凑点带为独立实测验证，可共享秒轴，但标题明确不同总体。实测实心/重建空心。说明启动/缓存/预处理口径，搜索重复先 case 内聚合再总体统计。更快但质量更低的 tradeoff 保留，均值差未显著不能写显著优势。

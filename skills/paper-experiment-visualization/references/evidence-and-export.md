# 证据、归一化与导出

## 绘图前

记录来源 SHA-256、endpoint 定义/方向/单位、实验单元、配对/重复、n、区间构造。窗口/重采样不自动成为独立患者。重绘复用冻结统计，不新增推断；缺少关键量时解释缺口，按授权做必要分析。

标题可靠优势应直接追溯数据/统计。图形不能决定采样、endpoint 或挑代表例规则。群体先于例证；例证预定义，或用声明过外部 endpoint 的中位效应规则。

## 信号与矩阵

PSD/谱图记录窗长、采样率、频率范围/单位。共同色域和归一化分母公平比较冗余/能量；逐模态归一化必须对应不同问题，不能默认。TFR 记录 log 与 display floor，区别归一化和物理幅度。

矩阵区分零、缺失、不可行、未评估。有符号比较以零为中心；隶属度用顺序色标/范围。绝对值与差值不混用图例，裁图保留色标/单位/方法。

## 输出与 QA

`scripts/publication_style.py` 为独立样式/导出助手。默认 183 mm 宽，600 dpi PNG，PDF fonttype 42，SVG 保留文字。SVG 在其他机器需要相应字体；需要轮廓时另存兼容副本。

固定物理尺寸，不用 tight bbox 改画幅。JSON 记录尺寸、实际字体、源哈希、绘图数据、文本边界与输出哈希。自动检查只检查文字越界，不能保证没有重叠、散点全部在轴内或科学论证正确。报告越界就改布局，不忽略。

示例统计是合成表，不是实验结果，不生成置信区间。换真实数据后更新协议、单位、headline 与来源。

逐项比对点估计/区间与冻结表，保留规定方法与全部观察，检查轴范围未截点或误差条。核对标题、图例、单位、n、分母、实测/重建标签、归一化。查看完整 PNG/PDF、密集局部与打印宽度；若只检查 PNG，就如实记录。

交付代码、统计、metadata、图件、简短报告。只改图时不改研究正文；要求集成时备份图、保持路径、按内容更新必要图注并依环境要求编译。Overleaf ZIP 核对 CRC、图件哈希和其他条目变化，保留 provenance。

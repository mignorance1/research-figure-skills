# 格式与颜色

## 模板优先

先查看作者提供的 Word 或 PDF 模板。保留其标题层级、页边距、字体、编号、行距、评论格式和图表表达。没有模板时，采用便于逐条阅读的正式回复文档；正文与引用清楚区分，标题保持黑色。

## 本套标记约定

以下是可复用的默认约定。已有模板或作者新批注采用其他含义时，更新实际样式及开头说明。

| 标记 | 含义 | 呈现方式 |
|---|---|---|
| 黑色 `000000` | 作者解释和答复正文 | 常规正文 |
| 绿色 `008000`，粗体 | 审稿意见原文 | 独立于作者答复 |
| 红色 `BE191E` | 新增证据或新增手稿摘录 | 引述手稿时配合斜体 |
| 蓝色 `1F4E79` | 展示调整及修改位置 | 位置可用较小字号 |
| 绿色 `008000` | 重写的定义与段落 | 摘录时用斜体，与绿色粗体的评论区分 |
| 橙色 `B45F06` | 记录的重要删除或替换旧文 | 明确标为原稿材料及其位置 |
| 下划线 | 回答当前评论的关键科学结论 | 选少量关键句 |
| 斜体 | 修订手稿中的直接引述 | 摘录内容与实际手稿一致 |

开头放 “Formatting of the response” 或对应中文说明。说明中的颜色词显示相应颜色，“Underlining” 或“下划线”显示下划线；评论示例按绿色粗体显示。仅声明实际使用的标记。

标红论文、干净论文与 response 的标记各有用途。开头分别说明它们的实际约定。例如论文仅用红色表示修改时，明确这条规则属于标红论文。

## 图表与公式

回复中的图表可使用独立编号，例如 Response Fig. R1、Response Table R1、Eq. (R1)。图题中列对应手稿标识与最终位置，确保来源明确。保持原图比例、图例和可读字号，避免同一证据被重复插入多次。

需要编辑公式时优先使用可编辑数学对象。已有复杂公式使用矢量或高分辨率图像时，保留公式源并查看真实导出效果。数学变量、矩阵、上下标、括号与数字沿用论文的符号约定。

数值表的粗体按本表的实际比较范围使用。机制构造、参数、运行调用数和配对效应是否加粗由当前作者批注决定。对已有表格的局部批注，只调整目标区域，并同步表注。

## 旧文记录

重要旧公式或旧解释可以放入单独专节，方便审稿人理解数学变化。明确标识它们已经被替换，附原稿位置，再解释新定义与证据。删除记录按需要保留，避免把原稿的大段正文搬入回复。
